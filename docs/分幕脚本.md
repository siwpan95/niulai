## 各幕节拍表（2026-10-18 依多源故事大纲核定）

> 节拍来源：维基百科 / 萌娘百科 / 今日头条完整故事大纲 / 新浪导演专访 / 云南日报影评，
> 交叉核对后核定，台账见 `docs/原片素材调研.md`第五节。原片对白极少（"少对白寓言"），
> 节拍密度主要靠姿态/事件/拟音/OST 支撑，不为凑数注水。

### 序幕 · 荒漠飞雀（6 min）

- 云玎自高空 (-88, 42, 55) 长镜头飞来（追雀机位 0–52s，确定性蜿蜒 + 转弯侧倾）
- 末 30s 过渡"雀 + 牛"双人镜头；牛来伏地挣扎
- **入梦问答**（328–360s，新增）：「我们不一样，是吗？」「是的——我们不一样，但我们也一样。」
  「那我也能像你那样从树上下来吗？」「那恐怕不行，那是飞，但是你会在地上跑起来的。」

### act1 站不起来（5 min）

- 绿地清晨，初生牛犊双腿无力；妈妈低头盼望（全景长镜头）
- 牛来伏地挣扎（侧摇/抬头/蹬后腿）；云玎伤翅落在一旁被照料
- 哺乳对话（"妈妈，我饿了"/"不是刚吃过吗"/"水滢滢喝了不生病，草青青好吃不想停"）
- "长大是将来的事"三代对白；日出双人镜头
- 妈妈起身走向牛群（梦境过渡白闪起）

### act2 迁徙与过溪（12 min）

- "秋黄未到……准备迁徙"；牛群收拾（36 头编队）
- 沙漠干渴；妈妈摘果子（"我给你们摘果子，吃完了，就有力气了！"）
- 遇草蛇：误以为"小绳头"上前被咬，留下心理阴影（见绳状物即恐）
- 过溪惧蛇：蛇逼近慌乱跳过小溪并撞树
- 跳前对话（"好吧妈妈，那就后天，我先跳过这条小溪，再去找大河。"新增）
- 撞树后（"跳小河撞树上啦？那哭的不应该是树吗？"新增）

### act3 豹拉（12 min）

- 草原深处初遇孤豹：**「我是豹啦。」**（140s 新增，豹拉走到初遇点）
- 牛来恳求母亲接济；分奶摘果；妈妈约法三章后允许
- 建立友谊（"满足你的胃，它会治愈悲伤的。"）
- 牛群戒备不接纳；狼群初袭，豹拉引开追兵
- **牛二诬告豹拉勾结野兽**（头条大纲节拍；无台词，用群体姿态/事件广播表现）
- 被迫分离（"就算分开我们还是朋友。"「相信我，我还会在你身后出现的。」）

### act4 狼袭与母亡（18 min）

- 迁徙夜狼群总攻（CombatEngine 31 节拍）；豹拉屡次挡击
- 牛群下峡谷休整，狼群再跟上
- 妈妈体力耗尽出现幻觉，不愿成为拖累
- 歪脖子树旁断后嘱托（补全原文）：「以后，如果你想妈妈了，就到这棵树下来吧。
  这儿会有妈妈的影子，也许它，能唤起你的回忆和斗志。」
- 母亲牺牲；牛来悲鸣（"妈妈……"）
- 本幕保持 3 句对白（原片少对白设定），密度靠夜戏拟音 + 紧张 OST 支撑

### act5 传承与决战（15 min）

- 岁月更迭（逐帧大气：白昼→黄昏→夜→黎明）；成年牛来长角成族群勇士
- 牛爸爸训诫（"跑不快的肥牛是要成为盘中餐的。"新增 / "翅膀硬了，自然要高飞了。"）
- 重回牺牲之地（歪脖子树）；**豹拉复刻妈妈嘱托断后**（新增仿写句，见调研 E3）
- 盗猎车现——噪音正是此前诡异声响来源（头条大纲节拍）
- 牛来战吼引开盗猎车（"打跑它们！好嘞！"）；"时间会证明牛来的。"（云玎句的成年复诵）

### act6 梦醒而立（12 min）

- 惊醒——原地仍是小牛（与 act1 同一构图，测试钉住复位）
- 借梦境之力奋力站起（腿绕髋顶拉伸、蹄高守恒）
- 云雀高飞；奔向牛群见父亲得认可（"翅膀硬了，自然要高飞了。"）

### act7 片尾（6 min）

- 一家三口 + 牛群 + 云雀金色黄昏定格；片尾主题民谣
