## 三、本机重制流水线（2026-10-18 实测）

```
bootstrap（venv 3.13.12 + PyPI 依赖 + imageio-ffmpeg 充当 ffmpeg）
  -> render_all.py（八幕 x 6 并发 x 2 分钟块，resume；act0-4 720p、act5-7 1080p）
  -> make_audio.py（6 组曲 + 3 拟音 + 6 spots，49s）
  -> assemble_film.py（numpy 混音 + 峰值硬校验 + mux + concat + 5160s 验收）
  -> 配音版（voice_mix.py，46 句，sapi/edge 双引擎）
```

环境坑位（实测）：
- winget 拉 GitHub 失败（0x80072efd）→ **imageio-ffmpeg 的 wheel 内置二进制**
  充当 ffmpeg（gyan 7.1 essentials 同源，含 libx264/aac）；
- PATH 上有坏桩 `ffmpeg.exe`（108KB，rc=1 无输出）→ 一律显式 `NIULAI_FFMPEG`；
- render_parallel `--seed` 默认 0 ≠ MASTER_SEED → 必须显式传，否则地形漂移。
